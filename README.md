## Haiku 5.5 Pricing vs Luna 6

- **Subagent tier**: $0.10 input / $0.50 output per million tokens under 100K context.
- **OSWorld score**: 72.4% on desktop task automation benchmarks.
- **Effort controls**: low, medium, and high reasoning budgets selectable per thread.
